# IIT26S Programming

A collection of introductory Python programming exercises for the IIT26S programming course. The repository contains small, focused programs designed to build confidence with input, output, arithmetic operations, variables, and basic problem-solving.

## Repository Contents

The exercises are organized by week and assignment:

```text
IIT26S_Programming/
├── W1/
│   ├── A1_T1.py
│   ├── A1_T2.py
│   ├── A1_T3.py
│   └── A1_T4.py
├── A1_T5.py
├── A1_T6.py
└── A1_T7.py
```

The current exercises include examples such as:

- Calculating the area of a wall
- Finding the remainder after division by 2
- Working with numeric user input
- Practicing arithmetic expressions and formatted output
- Building simple interactive console programs

## Requirements

- Python 3.8 or later

No external packages are required. All programs use Python's standard library.

## Getting Started

Clone the repository and move into its directory:

```bash
git clone https://github.com/ShakhawatUllah/IIT26S_Programming.git
cd IIT26S_Programming
```

Run an exercise with Python:

```bash
python W1/A1_T1.py
```

You can also run any of the root-level exercises, for example:

```bash
python A1_T5.py
python A1_T6.py
python A1_T7.py
```

On systems where `python` refers to Python 2, use `python3` instead:

```bash
python3 W1/A1_T1.py
```

## How to Use the Exercises

1. Select an exercise from the relevant week or assignment.
2. Run the file from a terminal.
3. Enter the requested values when prompted.
4. Review the output and modify the code to experiment with different solutions.

These programs are intended for learning and practice, so reading, running, and improving the code is encouraged.

## Learning Objectives

This repository provides practice with:

- Python syntax and program structure
- Variables and data types
- Console input using `input()`
- Converting text input into integers
- Arithmetic operators such as `+`, `*`, and `%`
- Formatted strings and readable output
- Breaking programming problems into small steps
